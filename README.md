# AI Recruiter Intelligence System — Phase 1

> **Current Project Phase:** Phase 1 — Project Foundation, Architecture & Core Infrastructure
> **Status:** In progress

Phase 1 establishes the production-quality technical foundation for the
AI-Recruiter-Intelligence-System final-year project: monorepo structure,
FastAPI backend, React frontend, PostgreSQL + Alembic, authentication
foundation (JWT + refresh cookies), Docker Compose local infrastructure,
tests, and documentation.

Future application features (verification, AI interviews, matching,
recruiter pipeline, messaging, …) are **intentionally not implemented** in
this phase. See `docs/PHASE_1.md` for the exact Phase 1 boundary.
